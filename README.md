# Tontine

Tontine est un projet visant à faciliter la gestion d'une tontine (association rotative d'épargne et de crédit) : suivi des cotisations, des membres et des tours de distribution.

## Statut

Projet en cours de démarrage. La structure technique et les fonctionnalités seront ajoutées au fil des prochaines contributions.

## Contribuer

Les contributions se font via des pull requests.
